Segurança & Privacidade

Proteção de dados em primeiro lugar

O TokenPulse foi projetado desde a primeira linha de código com rigorosas práticas de segurança defensiva.

Criar Minha Conta Segura
  • Criptografia Simétrica Fernet + HKDF
    Chaves de API nunca são salvas em texto puro. Cada chave é criptografada em repouso com derivação de salt por usuário.
  • Guarda Rigorosa Anti-SSRF
    Bloqueio ativo contra faixas de rede privada (RFC 1918) e endereços de loopback locais.
  • Mascaração de Segredos
    Segredos e chaves nunca são refletidos na interface web após configurados.
